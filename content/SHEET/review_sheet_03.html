📡 Review Sheet หน่วยที่ 3 — การออกแบบกลไกในระบบเมคคาทรอนิกส์
EN-132-012 Mechatronics Systems Design · Mechanism Design in Mechatronic Systems
สัปดาห์ที่ 4–5 · ท 4 / ป 6 ชม. · CLO2, CLO4
ใบงานปฏิบัติ 1 ใบงาน
📌 1. สาระสำคัญ

ระบบเมคคาทรอนิกส์เป็นการรวมงานกลไก อิเล็กทรอนิกส์ และการควบคุมเข้าด้วยกัน จึงต้องใช้ระเบียบวิธีออกแบบที่เป็นระบบ เช่น V-model ตามแนว VDI 2206 และใช้เครื่องมือ CAx ช่วยสร้างแบบจำลอง 3 มิติ วิเคราะห์ และผลิตต้นแบบ SolidWorks สร้างชิ้นงานจากสเก็ตช์ 2 มิติที่กำหนดเงื่อนไขครบถ้วน แล้วใช้ Features เพิ่ม-ตัด-ปรับแต่งเนื้องาน จากนั้นประกอบเป็น Assembly และตรวจสอบการชนกัน เครื่องพิมพ์ 3 มิติแบบ FDM ช่วยสร้างต้นแบบชิ้นส่วนกลไกได้รวดเร็ว โดยต้องออกแบบให้เหมาะกับกระบวนการพิมพ์ ประมาณมวล เวลา …

🎯 2. จุดประสงค์การเรียน (ทั่วไป)
  • 3.1 เข้าใจกระบวนการออกแบบระบบเมคคาทรอนิกส์และบทบาทของ CAx
  • 3.2 สร้างแบบชิ้นส่วนกลไก 3 มิติและงานประกอบด้วย SolidWorks ได้
  • 3.3 เข้าใจหลักการพิมพ์ 3 มิติแบบ FDM และเตรียมไฟล์พิมพ์ได้
  • 3.4 มีเจตคติที่ดีต่อความถูกต้องของแบบ ความปลอดภัย และการทำงานเป็นทีม
🧩 3. หัวข้อเนื้อหาในหน่วย
  • 3.1 กระบวนการออกแบบระบบเมคคาทรอนิกส์และสภาพแวดล้อม CAx
  • 3.2 พื้นฐานการใช้ SolidWorks
  • 3.3 Features สร้างและปรับแต่งชิ้นงาน
  • 3.4 การประกอบ การตรวจสอบ และการทำงานร่วมกันระหว่าง MCAD/ECAD
  • 3.5 เครื่องพิมพ์ 3 มิติแบบ FDM
  • 3.6 การออกแบบเพื่อการพิมพ์ และการคำนวณเบื้องต้น
📝 4. บทสรุป

ระบบเมคคาทรอนิกส์เป็นการรวมงานกลไก อิเล็กทรอนิกส์ และการควบคุมเข้าด้วยกัน จึงต้องใช้ระเบียบวิธีออกแบบที่เป็นระบบ เช่น V-model ตามแนว VDI 2206 และใช้เครื่องมือ CAx ช่วยสร้างแบบจำลอง 3 มิติ วิเคราะห์ และผลิตต้นแบบ SolidWorks สร้างชิ้นงานจากสเก็ตช์ 2 มิติที่กำหนดเงื่อนไขครบถ้วน แล้วใช้ Features เพิ่ม-ตัด-ปรับแต่งเนื้องาน จากนั้นประกอบเป็น Assembly และตรวจสอบการชนกัน เครื่องพิมพ์ 3 มิติแบบ FDM ช่วยสร้างต้นแบบชิ้นส่วนกลไกได้รวดเร็ว โดยต้องออกแบบให้เหมาะกับกระบวนการพิมพ์ ประมาณมวล เวลา และตรวจสอบความแข็งแรงเบื้องต้นก่อนพิมพ์จริง

❓ 5. คำถามทบทวน (จากแบบฝึกหัดท้ายหน่วย)
  • อธิบายความหมายของสเก็ตช์แบบ Under defined, Fully defined และ Over defined พร้อมสีของเส้นที่ปรากฏ
  • เรียงลำดับขั้นตอนการสร้างชิ้นงาน 3 มิติใน SolidWorks พร้อมยกตัวอย่าง Feature ที่ใช้ในแต่ละขั้น
  • เปรียบเทียบ Sweep กับ Loft ว่าต่างกันอย่างไร และยกตัวอย่างงานที่ใช้
  • เพราะเหตุใดจึงควรตรวจสอบการชนกัน (Interference Detection) หลังประกอบชิ้นส่วนใน Assembly
  • ชิ้นงานมีปริมาตร 32.7 cm³ เส้นพลาสติก PLA ความหนาแน่น 1.24 g/cm³ ถ้าพิมพ์เนื้อตัน มวลเท่าใด
  • ชิ้นงานตามข้อ 5 พิมพ์ด้วยสัดส่วนผนัง/ผิว 0.55 และ Infill 20% จงหาปริมาตรเส้นที่ใช้จริง มวล และความยาวเส้น …
⚠️ ข้อควรระวังด้านความปลอดภัย (ใบงานปฏิบัติ)
  • ตรวจสอบความเค้นดัดเบื้องต้นและสรุปตัวประกอบความปลอดภัย
