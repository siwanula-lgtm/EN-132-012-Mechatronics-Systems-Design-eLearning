📌 1. สาระสำคัญ

การเขียนโปรแกรมควบคุมคือการกำหนดขั้นตอนให้ตัวควบคุมอ่านค่าจากเซนเซอร์ ตัดสินใจ และสั่งแอคชูเอเตอร์ ภาษาที่ใช้ขึ้นกับแพลตฟอร์ม Python เหมาะกับพีซีสำหรับเก็บข้อมูลและทดสอบอัลกอริทึม Arduino C++ ทำงานบนไมโครคอนโทรลเลอร์ที่สั่งงานขาโดยตรง ด้วย PWM และ ADC Visual Basic ใช้สร้างหน้าจอควบคุมบน Windows แบบเหตุการณ์ และ PLC ใช้แลดเดอร์ที่ทำงานเป็นรอบสแกนในงานอุตสาหกรรม ทั้งสี่แบบสื่อสารกันด้วยพอร์ตอนุกรม (8N1) หรือสัญญาณ I/O และการเลือกอัลกอริทึม เช่น ON/OFF, P และ PI มีผลต่อความแม่นยำของระบบ (Shetty & Kolk, 2011)
